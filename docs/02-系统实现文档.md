# 系统实现文档

本文档描述当前代码实现。产品规则以 01-问卷与报告规范为准，数据处理以 04-数据隐私与保留策略为准，部署操作以 03-部署与运维文档为准。

## 1. 技术结构

~~~text
浏览器
  -> React + TypeScript + Vite
  -> 生产环境由 Nginx 代理 /api
  -> FastAPI
  -> PostgreSQL
  -> Kimi 或 DeepSeek
~~~

主要目录：

~~~text
frontend/src/
  app/                 路由和应用外壳
  pages/               问卷、报告、管理员和隐私页面
  api/                 前端接口封装
  components/          表单、报告渲染和语音按钮
  storage/             按账号隔离的本地草稿

backend/app/
  api/                 HTTP 路由
  schemas/             Pydantic 数据模型
  services/            校验、任务、画像、报告和权限
  llm/                 模型供应商适配
  speech/              语音转写适配
  storage/json_db.py   PostgreSQL 存储层（保留历史文件名）
~~~

## 2. 账号与权限

当前后端提供本地账号注册、登录、改密和当前用户接口。密码使用 PBKDF2-SHA256，登录 token 使用 HMAC 签名。

- 学生只能读取自己的任务、报告和反馈。
- 学生只能删除自己的报告或全部业务数据。
- 管理员可以查看学生记录、完整问卷、审计日志和编辑报告。
- 真实 jAccount 接入不在本轮实现范围，由学校侧负责。

## 3. 报告生成

报告使用持久化任务流程：

1. POST /api/assessment-jobs 校验问卷、检查账号并检查每日配额。
2. 任务及临时输入写入 PostgreSQL。
3. 后台任务领取租约并定时心跳。
4. 画像阶段调用当前模型并校验结构。
5. 报告阶段生成六模块 Markdown 并执行质量检查。
6. 保存问卷、画像、报告和报告版本，清除临时输入。
7. 前端通过 GET /api/assessment-jobs/{jobId} 轮询进度。

任务状态包括 queued、running、success、failed 和 cancelled。服务重启时会恢复可恢复任务；租约、claim token 和条件更新用于避免重复执行。每日生成配额默认关闭，设置正数后按账号限制创建次数；终态任务默认保留 30 天。

## 4. 数据库

数据库由后端启动时创建表，目前没有 Alembic 迁移。

| 表 | 用途 |
| --- | --- |
| users | 学生和管理员账号、每日生成和语音配额 |
| assessment_responses | 问卷主记录和 JSONB 答案 |
| assessment_scores | 能力与兴趣分数 |
| assessment_choices | 多选答案拆行记录 |
| assessment_drafts | 每个账号一份云端草稿 |
| career_profiles | 结构化用户画像 |
| reports | 当前报告 |
| report_versions | 报告生成和人工编辑历史 |
| generation_jobs | 任务状态、租约和临时输入 |
| report_feedback | 报告评分和反馈 |
| admin_audit_logs | 管理员敏感操作记录 |

业务记录通过 user_id、response_id、profile_id 等关联字段连接，复杂对象使用 JSONB 保存。问卷删除、报告删除和全部业务数据清除在数据库事务中执行。

## 5. API

### 5.1 认证

~~~text
POST /api/auth/register
POST /api/auth/login
GET  /api/auth/me
POST /api/auth/change-password
~~~

### 5.2 问卷和任务

~~~text
GET    /api/assessment-draft
PUT    /api/assessment-draft
DELETE /api/assessment-draft
POST   /api/assessment-jobs
GET    /api/assessment-jobs/{jobId}
POST   /api/assessment-jobs/{jobId}/cancel
POST   /api/assessments
~~~

PUT 草稿使用版本号进行乐观并发控制；版本冲突返回 409。POST /api/assessments 保留用于同步接口测试。

## 6. 前端路由

~~~text
/                         首页
/login                    登录
/register                 注册
/privacy                  隐私政策与数据管理
/assessment               问卷填写
/my-reports               我的报告
/reports/:reportId        报告详情
/reports/:reportId/feedback
/admin                    管理员后台
/admin/assessments/:responseId
/admin/reports/:reportId/edit
*                         404 页面
~~~

问卷草稿同时使用云端草稿和本地草稿。云端草稿按登录账号隔离，本地草稿使用带用户标识的存储键并设置过期时间。退出或 401 时清理当前账号草稿。

## 7. 语音转写

前端录音使用浏览器 MediaRecorder，后端统一接收 multipart 音频。当前内置讯飞录音文件转写适配器，录音结束后上传并轮询完整结果，不使用实时流式接口。SPEECH_PROVIDER=disabled 时功能关闭，音频不写入数据库。

## 8. 当前边界

- 没有真实 jAccount 集成。
- 任务状态持久化，但执行器仍在 FastAPI 进程内，不是独立队列服务。
- 数据表由应用启动时创建，没有正式迁移工具。
- 生产 Compose 只提供 HTTP，正式上线应放在 HTTPS 反向代理之后。
- 前端报告使用定制 Markdown 渲染器，不是完整 Markdown 解析器。
